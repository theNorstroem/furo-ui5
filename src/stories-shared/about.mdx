# フロー Furo UI5 components
For seamless integration into any Web Stack, the [SAP UI5 web components](https://ui5.github.io/webcomponents/) were extended with the data binding capability for the Eclipse furo open models (`@furo/open-models`).

## Framework agnostic #
The furo ui5 web components are regular web components.
Some are based on lit, some are extensions of the SAP UI5 web components and some are native components.
They work anywhere you use HTML, with any framework or none at all.
As a result of following the best practices for building web components, our components are also [FBP](https://fbp.furo.pro/) friendly.
