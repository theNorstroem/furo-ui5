# furo-ui5-form-row

> Single row within a form containing label and input field.

**Class:** `FuroUi5FormRow`
**Import:** `import "@furo/ui5/form-row"`
**Category:** FormLayout

**Related:** [`furo-ui5-form-group`](furo-ui5-form-group.md), [`furo-ui5-form-layout`](furo-ui5-form-layout.md), [`furo-ui5-label`](furo-ui5-label.md)

## Overview

The furo-ui5-form-row gives the user a layout to manage
input field and labels according to the design specification of SAP Fiori.

## Slots

### `label`
**Type:** `HTMLElement[]`

Slot for the label.
