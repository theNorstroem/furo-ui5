# Quick Reference

## Spacing Cheat Sheet
- `0.25rem` (4px) - Tight: icon gaps
- `0.5rem` (8px) - Small: related items
- `1rem` (16px) - Medium: form fields, cards
- `1.5rem` (24px) - Large: form groups
- `2rem` (32px) - XL: page sections

## Color Cheat Sheet
- **Green (Positive)**: Success, approved, active
- **Red (Negative)**: Error, rejected, failed
- **Orange (Critical)**: Warning, attention
- **Blue (Information)**: Info, highlight, new
- **Grey (Neutral)**: Default, inactive

## Button Placement Cheat Sheet
- **Left**: Destructive, reset, secondary
- **Right**: Cancel, close, primary (emphasized)
- **One Emphasized button per view**

## Typography Cheat Sheet
- **H1**: Page title (one per page)
- **H2**: Major sections
- **H3-H4**: Subsections, cards
- **H5-H6**: Minor headings
